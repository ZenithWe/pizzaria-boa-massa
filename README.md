# Pizzaria Boa Massa — Nova Lima

Site da Pizzaria Boa Massa, no bairro Cascalho, Nova Lima/MG.

## Conteúdo

- `index.html`: página principal, contatos e informações.
- `styles.css`: visual responsivo e temas claro e escuro.
- `script.js`: menu de navegação e controles de aparência.
- `preferences.js`: preferências de leitura salvas neste navegador.
- `assets/pizza-boa-massa.webp`: imagem ilustrativa da pizza.

## Visualizar

Abra `index.html` no navegador, mantendo os arquivos e a pasta `assets` juntos. Não é necessário instalar dependências nem compilar.

## Publicar

Envie os arquivos da raiz e a pasta `assets` para uma hospedagem estática. Ao definir o endereço final, atualize no `index.html` a URL canônica, `og:url` e os endereços do bloco de dados estruturados.

As fontes, o mapa e os links de pedido precisam de internet. O cardápio e os pedidos são atendidos pelos links externos do Anota AI e WhatsApp. Este projeto não contém um sistema próprio de pagamentos ou administração.

## Informações

Dados e depoimentos fornecidos em setembro de 2026. A fotografia é ilustrativa, gerada para o site. Os tamanhos, sabores e preços estão no cardápio externo.
